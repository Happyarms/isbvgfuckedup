# Dark Mode

Add a dark mode option that respects system preferences (prefers-color-scheme) and allows manual toggle. Ensure the bold JA!/NAJA/NEIN status colors remain readable and impactful in dark mode.

## Rationale
Many users check transit status early morning or late evening when dark mode is more comfortable. Improves accessibility and follows modern UX expectations. Maintains our differentiator of 'simple, unmistakable UI' (pain-1-4) in all lighting conditions.

## User Stories
- As a user checking status at night, I want dark mode so that the screen doesn't strain my eyes
- As a user with light sensitivity, I want dark mode so that I can comfortably read the status

## Acceptance Criteria
- [ ] Dark mode auto-activates based on system preference
- [ ] Manual toggle available in UI
- [ ] JA!/NAJA/NEIN colors are still bold and clear in dark mode
- [ ] All text remains readable with sufficient contrast
- [ ] User's preference is remembered
- [ ] Transition between modes is smooth
