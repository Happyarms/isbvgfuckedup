# Voice Assistant Integration

Enable voice assistant integration (Siri Shortcuts, Google Assistant Actions) so users can ask 'Is BVG fucked up?' and get a voice response with current status.

## Rationale
IsSEPTAFucked has Siri integration which users love. Voice queries are hands-free and quick - perfect for checking status while getting ready in the morning. Builds on our API to enable voice platforms.

## User Stories
- As a morning routine optimizer, I want to ask Siri 'Is BVG fucked?' while getting ready
- As a hands-free user, I want Google to tell me BVG status while I'm eating breakfast

## Acceptance Criteria
- [ ] Siri Shortcut available for iOS users
- [ ] Google Assistant Action available for Android users
- [ ] Voice response includes status and key metrics
- [ ] Documentation helps users set up voice integration
- [ ] Works with smart speakers (HomePod, Google Home)
