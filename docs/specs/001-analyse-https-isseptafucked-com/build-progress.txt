=== CRITICAL GOTCHAS FOR CODER AGENTS ===

1. ESM REQUIRED: hafas-client is ESM-only
   - package.json MUST have "type": "module"
   - Use import/export syntax, NOT require()
   - Jest needs NODE_OPTIONS='--experimental-vm-modules'

2. POLL-AND-CACHE: Do NOT fetch on every request
   - bvg-poller.js runs on setInterval (60s)
   - Routes serve pre-computed results from memory cache
   - First page load gets UNKNOWN until first poll completes

3. DELAY IN SECONDS: HAFAS delay field is in seconds, not minutes
   - Delayed = delay > 300 (5 minutes)

4. STALENESS: Mark status as UNKNOWN if data > 5 minutes old
   - On API error, keep serving cached data if not stale
   - Only mark UNKNOWN when no valid cache exists

5. STATION IDS: Use known BVG station IDs
   - Berlin Hauptbahnhof: 900003201
   - Berlin Alexanderplatz: 900100003
   - Berlin Zoologischer Garten: 900023201
   - Berlin Friedrichstra\u00DFe: 900100001
   - Berlin Ostkreuz: 900120005

6. EXPORT FOR TESTING: server.js must export the Express app
   - Supertest needs access to the app without listening
   - Poller.start() should be conditional (not during tests)
